# Machine Learning Assignments
This repository contains Machine Learning, Data Analysis, Image Processing, NLP, and Data Visualization projects implemented using Python and Jupyter Notebook.

## Projects

### 1. Satellite Image Analysis
Satellite image processing using pixel manipulation, RGB analysis, filtering, and image masks.

**Technologies:** Python, NumPy, Matplotlib, Scikit-Image

### 2. World GDP & CO₂ Analysis
Analysis and visualization of GDP per capita and CO₂ emissions using the World Indicators dataset.
**Technologies:** Python, Pandas, NumPy, Matplotlib

### 3. Geographic Visualization
Interactive visualization of global CO₂ emissions using a Folium choropleth world map.
**Technologies:** Python, Pandas, Folium, GeoJSON

### 4. Sentiment Analysis
Text sentiment classification using preprocessing, Bag-of-Words, and Logistic Regression.
**Technologies:** Python, Scikit-learn, CountVectorizer, SGDClassifier

### 5. Weather Data Analysis
Prediction of high afternoon humidity using morning weather conditions and a Decision Tree Classifier.
**Technologies:** Python, Pandas, Scikit-learn
